# JavaScript Canvas 

The `<canvas>` element allows you to draw 2D graphics using JS. For this element it is important to using it's closing tag; `</canvas>`  because this will ensure that the content will display on the browser. 
This element also features the `getContext()` method which returns a rendered context object. This method requires one argument which would be the type of context it contains. The 2D rendering context allows you to draw text, images, shapes and other objects. 

## Chart.js  Documentation 

**Chart.js**  is a JS library that makes it easier to create interactive charts on the web. It supports multiple chart types like pie charts, line charts, bar charts, etc. Also, it is the most popularly used on Github by developers. The way to bring **Chart.js** into a project is by using the **CDN** method. 

Displaying data via **Chart.js** does have some advantages like for example, get a pattern recognition from your users or seeing raw numbers of engagement on your page. Charts make it easier to interpret these numbers and just simplify complex data from your website as whole.
