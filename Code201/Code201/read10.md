# The JavaScript Debugger 

The JS Debugger is a tool that is built into your browser which allows you to oause your code so you can inspect it thoroughly.
**Breakpoints** list specific points in the code that you can verify carefully for errors. The **Call Stack** is a section that shows you what code was executed to get to a current line. With this, you can see what function the code is in and what **breakpoint** is paused on.
