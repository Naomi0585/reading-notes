# Images, Color and Text

We've been learning how code brings structure and functionality to a website but on this section we will learn how the added elements of images, colors and text can bring a website to life making it more atractive and even interactive. 

## HTML Media 

* <u>`alt`</u>

You've probably seen an `alt` attribute on a website before unknowingly. To get you familiarized, a good example of this attribute on a website would be maybe a navigation button that has an image. For this to be functional, `alt` would have to be accompanied by a text that identifies the context of the image or path. Formatting it this way makes your website functional and professional. 

By using a descriptive text the `alt` attribute clear specifics of an image even if the image is not visible. In conclusion, never rely on just images to communicate key info on your website. 

* <u>`figure`</u>

This element is useful when you have content like charts or diagrams that are related to the main content of the website but still could stand on their own. This element is useful for when you need captions to accompany your main content. 

## GIF vs. SVG 

To understand is simple terms, a **GIF** is like a flipbook filled with tiny pictures that move when you flip the pages. An **SVG** is a photo or drawing made up of instructions or descriptions rather than lines or dots, this image can be manipulated and the quality of it will remain the same. 

### <u>Screenshots:</u>

If you want to use a functional screenshot on your website it would be preferable to use a **Lossless WebP** or **PNG** format. The **WebP** format usually will be better compressed than **PNG**.

# Images, Color and Text in CSS

Imagine you just moved into a new house and you are decorating one of the rooms. The **Background Color** would be the color you choose to paint the walls in one of the rooms with. The **Foreground Color** would be the colors of a poster or decoration on that room's walls. On a website, this would translate as follows; **Background Color** sits behind all of the other elements in the website. The **Foreground Color** would be the color of the content that sits on top of the background.  

## Colors

When it comes to using colors in a website I personally use them to add personality and capture the attention of the reader while keeping in mind that its visually readable. No strain on the eyes! I also like choosing a base color and using complementing colors for the other elements on the page. Personally, I like using a light background color and then make the foreground colors darker to make them "pop". The contrast is very important when you are doing color combinations in order to give it an organized look. Accenting important stuff with bright colors so they are not missed by the reader and being consistent with the colors you use for links so it is understood that certain elements can be clicked. 

## Text 

For me, when picking a font for the text I consider what is the general theme of the website and pick a font style that complements it. Also, keeping consistent fonts makes the website look more concise as a whole. Using bolder versions of the same font for emphasis is a good practice. These are just stylistic considerations but in general I think the font being readable is the most important thing to consider. 

* `font-size` = How big or small the text is.
* `font-weight` = How thick (bold) or thin the text is. 
* `font-style` =  How the font looks. For example, for a slanted look you would itilize the text. 

<u>`h1`</u>

There's a few ways you can add spacing around the characters displayed in an `h1` element. **Spacing** adds space in between the characters and **Padding** would add space around the characters. If you want to add space outside the characters instead, you could use the **margin** element.
