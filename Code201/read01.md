# Intro to HTML

**HTML** contains *attributes*, these provide extra infromation about HTML elements. Attributes also modify of describe elements. 
Some examples of HTML attributes are; `src`,`class`,`alt`,etc. 

## The anatomy of HTML
An HTML element should be structured as follows; 
`<opening tag>` ⤑ `<content>` ⤑ `</closing tag>`.

In **HTML** an `<article>` is content that can stand alone like a post or news article and a `<section>` is related content in the same page like for example sections or chapters. 

### Typical HTML elements: 
* `<main>`
* `<header>`
* `<nav>`
* `<footer>`
* `<body>` 
* and more! 

### <u>MetaData</u>

*MetaData* helps search engines know what your page is about. It narrows down the description so its easier to search for the website. The meta tag is placed inside the `<head>` element and this provides the context of what the wesite is about. This action will display better results for search engines to find the web.

### <u>Semantics</u>

It is very important to use the correct structure for your website so it becomes more accesible and the screen readers can work. For instance, using `<h1>` instead of `<span>` for making a header or title is better for SEO standards. 

Semantic tags make the **HTML** easier to read and understand, improve accessibility, help search engines and make code simple. 

### <u>JavaScript</u>

There are specific elements you would need from JavaScript in order to show certain things in your browser. For example, if you wanted to implement interactions on your website like buttons or pop-ups you would need a JavaScript code for that. 

You can add *JavaScript* to an HTML document by writting a JavaScript tag in your HTML file within the body like this; `<script>`.
