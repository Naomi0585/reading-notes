# Event Driven Applications 

**What native Node.js module allows us to get started with Event Driven Programming?** 

* The native Node.js module is called events. It provides the `EventEmitter` class, which allows developers to create, trigger, and listen for events. This helps applications respond to specific actions without having to constantly check whether something has happened.

**How Event Driven Programming might be useful on the backend using Node.js.**

* Event Driven Programming allows a website or application to respond automatically when something happens. On the backend, Node.js uses events to handle different tasks without constantly checking for changes. For example, when a customer places an order online, that action can trigger several events, such as saving the order to a database, updating inventory, and sending a confirmation email.This is similar to clicking a button on a website and seeing something happen, but the backend handles tasks that users don't directly see. For example, when someone logs into an account, the backend checks their information to make sure it's correct. When someone uploads a picture, the backend processes and stores the file. Event Driven Programming allows Node.js to respond to these actions using event listeners, which trigger specific functions when an event occurs. This helps applications handle different tasks efficiently while keeping the code organized and allowing different parts of the system to work independently.



## Object Oriented Programming 

*Object Oriented Programming* helps organize code into classes and objects, making it easier to manage and reuse. When combined with Event Driven Programming, objects can generate events and respond to them. This makes applications more organized, flexible, and easier to maintain because different parts of the program can communicate without being tightly connected.
