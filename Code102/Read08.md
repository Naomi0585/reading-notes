# Operators and Loops #

1. **What is an expression in JavaScript?**

- It is any piece of code, including diferent operators combined, that produce a value.

2. **Why would we use a loop in our code?** 

- Loops are helpful when you have to repeat a task. The loop is like an assistant so you dont have to continuously make inputs, instead a loop can help you go through lists and running a code until  a condition is met.

3. **When does a `for` loop stop executing?** 

- A `for` loop will stop executing when the condition for it becomes false. 

4. **How many times will a `while` loop execute?** 

- A `while` loop will continue as long as the condition is true to it's specifications or until the conditions become false. 

*`for` loop will only run until conditions are met. `While` loops will run even when the condition is not met*.
