# Programming with JavaScript #

**What is `control flow`?**

- *Control flow* is the order in which the computer executes statements in a script.

**What is a JavaScript `function`?**

- A *function* is a code snipet that can be called by other code on by itself; on a variable that refers to the function. 

**What does it mean to `invoke` or `call` a function?**

- *Calling* a function performs the specified actions with the indicating parameters. 

**What are the parentesis `()` for when you define a function?**

- When you define a function the parenthesis are used to hold the parameters (inputs) the function can receive.
