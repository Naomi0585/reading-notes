# Dynamic Web Pages with JavaScript # 

## An Introduction to JavaScript ## 

Within JavaScript there are **Variables** and these, are containers for data. Variables are identified with unique names called *Identifiers*.

- To 'declare' a *variable*  it means to create a variable and give it a name to tell the computer what kind of data it will store. 
- An **Assigment Operator** assigns a value to its left operand based on the value of its right operand and vice-versa. 
- Information received from the user is known as 'input' and/or 'userinput'.
