## REST & HTTP

**Who is Roy Fielding?** 

 Roy Fielding is a computer scientist best known for helping create the HTTP protocol and for defining REST (Representational State Transfer). His work shaped how websites and APIs communicate over the internet.
Fielding and his friends created  *Hypertext Transfer Protocol*(HTTP) as a standard set of rules that allows computers and servers to communicate across the web. It defines how requests are sent and how responses are returned so different machines can exchange information reliably.

**Why don’t the techniques that we use in this class work well when we need to be able to talk to all of the machines in the world?**

*  The techniques we use in class often work within one program or one local system, but the internet connects millions of different computers using different operating systems and programming languages. Because of that, machines need a universal set of rules for communication. Without a shared standard, systems would struggle to understand each other.

```Javascript
GET = asks a server to retrieve information. Used when you want to view data without changing anything.

POST =  sends new data to a server so it can update or create something. 

PUT = replaces or updates an entire existing resource on the server. 

PATCH = updates only part of an existing resource instead of replacing everything. 
```
